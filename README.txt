# Implementação BFS e DFS

    Esse projeto implementa os algoritmos de busca em largura e em profundidade
    para a resolução de um labirinto

Autores:
    Gabriela Guse Machado e Pedro Santos Pozza

---

## Arquivos presentes

- main.py;
- maze_generator.py;
- bfs_algorithm.py;
- dfs_algorithm.py.

## Instruções de uso:

    Executar o programa main.py para visualizar resultados obtidos em baterias de
    testes. Para depurar especificamente cada método ou a geração do labirinto,
    executar os programas separadamente. Todos as saídas são exibidas no terminal
    onde o executável foi invocado.
